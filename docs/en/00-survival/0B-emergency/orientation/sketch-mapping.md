# Scale and Symbol Systems

## Objective
The objective of using consistent symbol systems and an accurate scale bar is to turn a field drawing into a map that anyone in a group can read and trust.

## Dependencies and prerequisites
*   Agreement among mapmakers on a single symbol for each feature type.
*   Calibration of pace based on measured ground distance.

## Material
*   Field drawings.
*   Durable piece of card or board for the master legend.
*   Paper for sketching.
*   Compass.
*   String (for measuring distances).

## System
### Symbol System
A consistent symbol system is a visual language that allows maps to be interchangeable, enabling new group members to read existing maps instantly.

**Symbol Categories:**
*   **Point Symbols (Features at a specific location):**
    *   Water source (spring, well):
        *   Small circle with dot (Water source)
        *   Small circle, half-filled (Intermittent water)
    *   Campsite / shelter:
        *   Triangle (Campsite / shelter)
        *   Filled triangle (Permanent settlement / building)
    *   Ruin / abandoned structure:
        *   Square
    *   Danger zone:
        *   X
    *   Observation point / high ground:
        *   Star (4-point)
    *   Medical cache / first aid:
        *   Plus sign
    *   Resource extraction (quarry, mine, clay pit):
        *   Crossed picks
    *   Marker / waypoint:
        *   Flag (vertical line + triangle)

*   **Line Symbols (Features that form lines):**
    *   Trail / path (confirmed):
        *   Solid line
    *   Trail (uncertain or overgrown):
        *   Dashed line (Line with gaps every 5mm)
    *   Road / wide track:
        *   Double solid line
    *   Stream / small river:
        *   Wavy single line
    *   Large river:
        *   Wavy double line
    *   Fence / barrier:
        *   Line with perpendicular ticks
    *   Cliff / steep drop:
        *   Line with V shapes
    *   Boundary / edge of area:
        *   Dotted line
    *   Planned route:
        *   Dashed-dot line

*   **Area Symbols (Features covering an area):**
    *   Deciduous forest:
        *   Small circles scattered
    *   Coniferous forest:
        *   Small triangles scattered
    *   Mixed forest:
        *   Mixed circles + triangles
    *   Swamp / marsh:
        *   Horizontal dashes
    *   Sand / bare ground:
        *   Stipple (dots)
    *   Grassland / meadow:
        *   Tufts (small V shapes)
    *   Open water (lake, pond):
        *   Horizontal lines
    *   Impassable terrain:
        *   Cross-hatching

*   **Elevation Symbols:**
    *   Slopes:
        *   Hachures (Short parallel lines pointing downhill, perpendicular to contour)
    *   Approximate contours:
        *   Form lines (dashed curves following terrain shape)
    *   Spot height:
        *   Number with triangle (Small triangle with elevation number beside it)
    *   Water flow direction:
        *   Arrow in stream (Small arrow following stream direction)

### Scale System
Scale is a ratio representing map distance to ground distance.

**Scale Ratios:**
*   1:5,000 means 1 unit on the map equals 5,000 units on the ground (e.g., 1 cm map = 50 meters ground).
*   1:25,000 means 1 cm = 250 meters.
*   1:100,000 means 1 cm = 1,000 meters (1 km).

**Choosing the Right Scale (Coverage for A4 Paper 21 x 29 cm):**
| Situation | Recommended Scale | Coverage for A4 Paper (21 x 29 cm) |
| :--- | :--- | :--- |
| Camp layout, building plans | 1:100 to 1:500 | 21m x 29m to 105m x 145m |
| Settlement and immediate surroundings | 1:1,000 to 1:5,000 | 210m x 290m to 1.05km x 1.45km |
| Local area, daily foraging range | 1:10,000 to 1:25,000 | 2.1km x 2.9km to 5.25km x 7.25km |
| Regional, multi-day travel routes | 1:50,000 to 1:100,000 | 10.5km x 14.5km to 21km x 29km |

**Accurate Scale Bar:**
A scale bar is preferred over a written ratio because it remains accurate when the map is copied at a different size.

**Measuring Distance on a Map:**
1. Mark the two points on the map.
2. If the route is straight, lay a strip of paper between them, mark both ends, then lay the strip against the scale bar and read the distance.
3. If the route follows a curved path (trail, river), lay a piece of string along the curved route, then straighten the string against the scale bar.

### Pace-to-Scale Conversion

**Calibrating Your Pace:**
1. Measure a 100-meter course with a rope or known reference distance.
2. Walk it normally three times, counting double paces (left foot hits the ground counts as one).
3. Average the counts to find the pace factor: **100 / average count = meters per pace**.

**Pace Count Correction Factors:**
| Condition | Correction Factor | Example (65-pace baseline) |
| :--- | :--- | :--- |
| Flat ground, no load | 1.0 (baseline) | 65 paces / 100m |
| Uphill (moderate) | 1.10 - 1.15 | ~72-75 paces / 100m |
| Steep uphill | 1.20 - 1.30 | ~78-85 paces / 100m |
| Downhill (moderate) | 0.95 - 1.0 | ~62-65 paces / 100m |
| Steep downhill | 1.05 - 1.15 | ~68-75 paces (shorter, cautious steps) |
| Heavy load (>20 kg) | 1.10 - 1.20 | ~72-78 paces / 100m |
| Dense brush / snow | 1.15 - 1.30 | ~75-85 paces / 100m |
| Night travel | 1.10 - 1.25 | ~72-81 paces / 100m |

**Converting Paces to Map Distance (Formula):**
Map distance (cm) = (paces x meters per pace) / scale denominator x 100

**Example:** Walked 130 paces at 1.54 m/pace on a 1:5,000 map.
Ground distance = 130 x 1.54 = 200.2 meters.
Map distance = 200.2 / 5,000 x 100 = 4.0 cm. Draw a 4.0 cm line on the map.

### Sketch Mapping Technique
**Procedure:**
1. Take a compass bearing to the next visible waypoint.
2. Walk to that waypoint, counting paces.
3. Draw a line from the start point in the bearing direction, at the correct scaled length.
4. At the new waypoint, quickly sketch nearby features.
5. Repeat until a known mapped point is reached.
6. Compare sketched routes with known positions; calculate closure error.

**Speed vs. Accuracy Tradeoffs:**
| Approach | Time | Accuracy | Best For |
| :--- | :--- | :--- | :--- |
| Bearing + pace every 50m | Slow | High | Detailed area mapping |
| Bearing + pace at turns only | Moderate | Good | Trail mapping, route recording |
| Estimated bearing + estimated distance | Fast | Low | Rapid reconnaissance, first exploration |
| Freehand sketch from observation | Fastest | Very low | Quick notes, not for navigation |

### Combining Multiple Sketch Maps
1. Identify overlap points (features on both maps).
2. Align maps at overlap points; discrepancies indicate error in pace counts or bearings.
3. Redraw a combined map, averaging shared feature positions.

## Process
### Establishing a Symbol System
1. Agree on symbols for all features.
2. Draw a reference sheet with every agreed symbol and its meaning.
3. Test readability using an unassigned mapmaker.
4. Train new members on the symbol system.

### Sketch Mapping Procedure
1. Determine starting point and compass bearing to the next waypoint.
2. Walk to the waypoint, counting paces.
3. Draw the scaled line on paper.
4. Sketch nearby features at the waypoint.
5. Repeat.

### Pace-to-Scale Conversion
1. Calibrate pace on measured ground.
2. Apply the appropriate correction factor based on terrain, load, and conditions.
3. Use the conversion formula to determine the map distance.
4. Draw the resulting scaled line on the map.

## System
### Scale System
Scale is a ratio (map distance to ground distance) expressed as a scale bar, which remains accurate when the map is copied or resized.

### Symbol System
Standardizing point symbols (springs, camps, danger zones), line symbols (confirmed trails, streams, cliffs), and area symbols (forest, marsh, grassland) ensures ambiguity is removed.

### Pace System
Distance measurement relies on pace counts calibrated to ground distance, adjusted by correction factors for terrain and load.

## Notes
*   **Common Mistakes:**
    *   Symbols being too similar (distinguish by shape, not just size).
    *   Forgetting to include a scale bar (a map without one is a sketch).
    *   Using body-relative directions instead of compass bearings (e.g., "Turn left at the big tree").
    *   Distorting scale to fit more area on the paper.
    *   Forgetting to orient the map to north before use (the most common navigation error).
*   **Key Takeaways:**
    1. Standardize symbols and create a master legend.
    2. Always include a scale bar.
    3. Calibrate pace and apply correction factors.
    4. Sketch maps are accurate enough for field navigation.
    5. Orient the map to north before using it.
