# Landmark Memory: Back-Bearings and Mental Maps

## Objective
To avoid getting lost by developing effective navigation skills based on back-bearings and mental maps, which are the foundation of all overland travel.

## Dependencies and prerequisites

*   **Practice:** Spatial memory improves dramatically with consistent practice.
*   **Mental Discipline:** The ability to constantly look back and observe the return view.

## Material

*   **Terrain Features:** Distinctive boulders, large trees, rock formations, streams, ridges, and trails.
*   **Decision Points:** Trail forks, ridge saddles, and stream crossings.

## System

The system relies on two core components: Landmark Memory (studying return views) and Mental Mapping (building an internal spatial model of traveled terrain).

## Technology

*   **Technology Used:** None explicitly required for the core techniques, as the focus is on observational navigation.

## Tools

*   **Essential Tools:** A compass (for professional back-bearings, though the concept works without one).
*   **Physical Markers:** Cairns (three stacked rocks), broken branches, or scratch marks to mark correct return paths.

## Process

### Landmark Memory (Back-Bearings)
1.  **Stop and Study:** Every time a distinctive feature is passed, stop and study the landscape behind.
2.  **Note Prominent Features:** Note the shape of the ridge, position of trees, or gap between hills.
3.  **Verbalize:** Say aloud the return view (e.g., “Coming back, the split rock will be on my RIGHT”).
4.  **Mark Path:** At decision points, spend 30 seconds studying the return view and mark the correct path.

### Building a Mental Map
1.  **Establish Anchor Point:** Before leaving, identify 2-3 landmarks visible from multiple directions to serve as anchors.
2.  **Categorize Elements (The Five Elements):** Actively categorize what is seen into Paths, Edges, Districts, Nodes, and Landmarks.
3.  **Narrate Route:** Build a verbal sequence of the route (e.g., “Camp → gravel-bar crossing → pine forest → old foundation”).
4.  **Estimate Time:** Between landmarks, estimate travel time rather than relying solely on distance.
5.  **Update Continuously:** Constantly check 360 degrees and update the mental map with new vantage points.

### Baseline and Catch Feature
*   **Baseline:** Identify a long, unmissable linear feature (road, river, coastline) before starting. If lost, head toward the baseline.
*   **Catch Feature:** Identify a prominent landmark beyond the destination that signals when the traveler has overshot.

### Sketch Mapping
1.  Draw the baseline at the bottom.
2.  Mark the starting point on the baseline.
3.  Draw the route as a line, marking landmarks and decision forks.
4.  Add approximate distances or times.

### Training Methods
*   **Narration Walk:** Narrate the route out loud as if explaining it to a follower.
*   **Reverse Challenge:** Walk a known route and try to describe it in reverse order.
*   **Sketch Test:** Draw a sketch map from memory after a return trip to compare with reality.
*   **Anchor Game:** Immediately identify three landmarks upon arrival and name them to train spatial anchoring.

## Notes

*   **Common Errors:** Overconfidence in memory ("I’ll remember this"), following animal trails, tunnel vision, overestimating distance, and ignoring back-bearings.
*   **Good Landmark Criteria:** Landmarks must be Unique, Visible from multiple directions, Permanent, and located at decision points.
*   **Reliability:** Time estimation is more reliable than distance estimation due to variable terrain difficulty.
