# Spring Snare

## Objective
To use stored energy in a bent sapling to yank a running noose tight and lift the catch off the ground, killing the animal quickly and protecting it from ground predators.

## Dependencies and prerequisites
- **Engine Tree:** A living, flexible sapling or branch is required. Dead or brittle wood snaps instead of springing.
- **Location:** Must be set near an active animal trail.
- **Target Game:** Rabbit-sized game requires a thumb-thick sapling base.

## Material
- **Engine Tree:** Flexible hardwood (hazel, willow, birch, maple saplings work well).
- **Snare Line:** Wire or strong cordage for the running noose.
- **Noose Diameter:** 10 cm diameter for rabbit-sized game.
- **Snare Line Length:** 45–60 cm (18–24 inches).
- **Leader Line (Cordage):** Strong cordage, at least twice as strong as what the target animal can break.
- **Trigger Mechanism:** Trigger stick and a trigger base (stake or peg).

## System
- **Mechanism:** The system uses a bent sapling as a power source to jerk the noose tight, lifting the animal into the air within a fraction of a second.
- **Kill Mechanics:** Cervical dislocation via sudden upward acceleration, snapping the neck.
- **Catch Height:** The lift height should be at least 60 cm (2 feet) off the ground.

## Technology
- **Spring Power:** Stored energy in a bent tree or sapling to provide the upward force.
- **Trigger Tuning:** The trigger must be sensitive enough for a walking rabbit to trip it, but stable enough to ignore wind, rain, and falling leaves.

## Tools
- Trigger stick.
- Sturdy peg or forked stake (for the trigger base).
- Long stick (for testing the trigger).
- Guide sticks (if using cordage to support the noose).

## Process
### Building the Standard Spring Snare
1. **Prepare the snare noose:** Make a running noose sized for the target animal (e.g., 10 cm diameter for a rabbit).
2. **Prepare the leader line:** Cut strong cordage to connect the tip of the engine tree to the trigger mechanism.
3. **Bend the engine tree:** Slowly pull the sapling tip down toward the trail; pre-bend over several hours if necessary.
4. **Set the trigger base:** Drive a sturdy peg or forked stake firmly into the ground beside the trail, directly below where the sapling tip reaches.
5. **Connect leader line to trigger stick:** Tie the leader line from the sapling tip to the top of the trigger stick, ensuring the trigger stick hooks under the base peg.
6. **Attach the snare noose:** Tie the snare line to the leader line or directly to the trigger stick.
7. **Position the noose:** Set the noose at head height for the target animal, supported by guide sticks if using cordage.
8. **Test the trigger:** Gently tap the trigger from a safe distance. Adjust trigger surfaces to find the balance between sensitivity and stability.

### Tuning the Trigger Sensitivity
- **Target Force:** The trigger should release at roughly 0.5–1 kg of lateral release force.
- **Adjustments:**
    - Too stiff: Shave down the contact surfaces.
    - Too sensitive: Deepen the hook notch slightly.

### Environmental Adjustments
| Condition         | Adjustment                                                                 |
| ----------------- | -------------------------------------------------------------------------- |
| High wind         | Deepen the trigger hook notch; add shielding brush around the trigger       |
| Rain/ice          | Smooth the trigger surfaces — moisture adds friction that prevents release |
| Frozen ground     | Use a rock anchor instead of a driven peg for the trigger base         |
| Heavy snow        | Raise the entire assembly; snow buries low-set triggers overnight        |
| Very cold weather | Warm metal wire before forming the noose                      |

### Improvised Spring Pole (If no sapling is available)
1. Cut a flexible green branch 2–3 meters long and thumb-thick.
2. Drive a sturdy forked stake into the ground near the trail.
3. Lay the branch across the fork, weighted or staked on the far end.

### Strategy and Usage
- **Best Trails:** Use spring snares on the best trails with the most animal traffic.
- **Set Strategy (Hybrid Approach):**
    - Set 3–5 spring snares on prime trails.
    - Set 10–15 passive snares on secondary trails.
- **Maintenance:** Check the entire circuit twice daily.

## Notes
- **Engine Tree Quality:** The primary requirement for the engine tree is flexibility; dead wood fails to provide the necessary spring power.
- **Safety:** When setting the snare, approach from behind the engine tree, not from the noose side, to prevent the leader line from whipping toward the operator if the trigger releases prematurely.
- **Comparison Summary:** Spring snares offer a faster kill (neck snap) and better predator protection compared to passive snares, but require 20–30 minutes to build.
