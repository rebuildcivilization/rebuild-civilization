# Leaf Patterns | Survival Wiki

## Objective
To use leaf patterns as the single most useful feature for identifying plants in the field.

## Dependencies and prerequisites

Successful identification requires combining leaf observations with [Flower Recognition] and [Seasonal Changes] for maximum accuracy. A single feature is never enough.

## Material

### Leaf Arrangement
*   **Alternate:** Leaves emerge one at a time, staggered along the stem in a spiral pattern.
    *   Recognition: Run a finger up the stem; if each node has a single leaf, and they alternate sides.
*   **Opposite:** Leaves emerge in pairs directly across from each other at the same point on the stem.
    *   Recognition: Look at a node; if two leaves emerge from the same point, one on each side of the stem.
*   **Whorled:** Three or more leaves emerge from the same point on the stem, radiating outward like spokes of a wheel.
    *   Recognition: Count leaves at a single node; if three or more radiate from the same point.

### Leaf Type
*   **Simple Leaves:** A single, undivided blade attached to the stem by one petiole (leaf stalk).
    *   Shape Examples: Ovate (egg-shaped), Lanceolate (lance-shaped), Cordate (heart-shaped), Palmate (hand-shaped), Orbicular (round).
*   **Compound Leaves:** The blade is divided into multiple separate leaflets.
    *   Types: Pinnately compound (leaflets along a central rachis), Palmately compound (leaflets radiate from a single point), Bipinnately compound (leaflets divided into sub-leaflets).

### Leaf Margins (Edges)
| Margin Type | Description | Common Examples |
| :--- | :--- | :--- |
| Entire (smooth) | Edge is completely smooth with no teeth or lobes | Willow, dogwood, magnolia |
| Serrate (toothed) | Small, sharp teeth pointing forward like a saw blade | Stinging nettle, cherry, elm |
| Doubly serrate | Large teeth with smaller teeth on them | Birch, elm, hazel |
| Crenate (rounded teeth) | Scalloped edge with rounded bumps | Ground ivy, catnip, violet |
| Lobed | Deep indentations creating distinct lobes | Oak, maple, grape, hawthorn |
| Spiny | Stiff, sharp points along margin | Holly, thistle |

### Leaf Surface and Texture
*   **Hairy / fuzzy:** Common in borage family (comfrey, borage), mullein, some mints.
*   **Waxy / glossy:** Indicates thick cuticle for water retention, common in dry-climate plants.
*   **Rough / sandpapery:** Elm, borage, some nettles.
*   **Smooth on top, hairy beneath:** Many trees (requires flipping leaves over).
*   **Sticky / resinous:** Often aromatic plants (some sages, gumweed).
*   **Translucent dots:** Characteristic tiny oil glands visible when backlit (St. John’s wort).

### Leaf Veins
*   **Pinnate venation:** One central midrib with branching side veins (like a feather). Most broadleaf plants (oak, beech, cherry).
*   **Palmate venation:** Multiple main veins radiating from the leaf base (maple, grape, wild geranium).
*   **Parallel venation:** Veins run parallel to each other from base to tip; the hallmark of monocots (grasses, cattails, lilies, onions, irises).

## System

### Tools
*   **Field Checklist:** A comprehensive tool to structure observations.
*   **Quick-Reference Decision Tree:** A structured flow to narrow down potential families.

### Process

**Field Checklist Steps:**
1. Arrangement (Alternate / Opposite / Whorled)
2. Type (Simple / Compound (pinnate, palmate, bipinnate))
3. Shape (Ovate, lanceolate, cordate, palmate, orbicular, or other)
4. Margin (Entire, serrate, crenate, lobed, spiny)
5. Surface (Smooth, hairy, waxy, rough, sticky)
6. Veins (Pinnate, palmate, parallel)
7. Smell when crushed (Pleasant, aromatic, bitter, none).

**Quick-Reference Decision Tree Logic:**
1. Check if the stem is square: 
    *   YES → Mint family (usually safe, check flowers to confirm).
    *   NO → Proceed.
2. Check if leaves are opposite: 
    *   YES → Limited families: mint, dogwood, honeysuckle, olive.
    *   NO → Proceed.
3. Check if the leaf is compound: 
    *   YES → Count leaflets: 
        *   3 leaflets → Could be clover (safe) OR poison ivy (danger). Check for glossy surface and middle leaflet on longer stalk.
        *   5+ pinnate leaflets → Walnut family, ash, elderberry, rose family.
        *   Many fine leaflets (bipinnate) → Legume family or fern.
    *   NO → Simple leaf. Check margin and shape against tables above.

## Notes

*   Alternate arrangement plus serrate simple leaves strongly suggest the rose family (Rosaceae), which includes many edible fruit-bearing plants.
*   Parallel veins indicate monocots (grasses, cattails, onions, lilies), which is a completely different group from broadleaf plants, requiring cross-reference with smell and habitat.
*   The 'Rule of Three' regarding compound leaves is used to identify poison ivy: three leaflets, the middle one on a longer stalk, often glossy, and sometimes with a reddish tinge in spring and autumn.
*   The key takeaway is that no single feature is sufficient; confidence is built by combining leaf observations with stem, flower, and habitat data.
