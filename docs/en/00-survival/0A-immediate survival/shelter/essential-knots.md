# Essential Knots

## Objective
To identify and master critical survival knots which are the irreducible minimum for survival.

## Dependencies and prerequisites
*   Working set of 8 to 10 reliable knots.
*   Cordage (plant fiber, paracord, wire, torn cloth strips, or wet rawhide).
*   Ability to tie knots reliably under stress, in the dark, with cold hands, and with available cordage.

## Material
*   **Core Eight Knots:** Bowline, Figure-8 Loop, Clove Hitch, Taut-Line Hitch, Sheet Bend, Square Knot, Trucker’s Hitch, Timber Hitch.
*   **Cordage Types:** Plant fiber, paracord, wire, torn cloth strips, wet rawhide.

## System
Knots are categorized to help select the correct knot based on the required function (Loop, Hitch, Bend, Binding, Compound).

## Technology
The core principle is that knowing a limited, highly versatile set of knots is superior to knowing many knots poorly.

## Tools
*   A set of core knots to practice.
*   A mechanism for testing proficiency (e.g., shuffled cards or random calls).

## Process
### Knot Selection Criteria
Knots are selected based on three criteria:
1. **Versatility:** Each knot must cover multiple use cases.
2. **Reliability:** Each knot must hold under load and not slip when tied correctly.
3. **Simplicity:** Each knot must be learnable in minutes and retained through infrequent practice.

### Practice Protocol
**Daily Practice (10 minutes):**
1. Pick two knots from the core eight.
2. Tie each knot five times, untying between attempts.
3. Time yourself. Proficiency standard: tying any core knot in under 15 seconds.
4. On the last repetition, tie by touch alone (eyes closed).

**Weekly Test (5 minutes):**
1. Have someone call out random knot names or use shuffled cards.
2. Tie each called knot as fast as possible.
3. Knots taking more than 20 seconds or requiring a restart go back into the daily practice rotation.

**Stress Inoculation:** Practice under adverse conditions, including wearing gloves, using only one hand (where applicable, like the bowline), in the dark, with wet rope, or with unfamiliar cordage.

### Core Eight Knots and Their Functions
| Knot | Category | Primary Use | Strength Retention | 
| :--- | :--- | :--- | :--- | 
| Bowline | Loop | Fixed loop that won’t slip | 60-75%
| Figure-8 Loop | Loop | Climbing-grade fixed loop | 75-80%
| Clove Hitch | Hitch | Attach rope to pole/post | 60-65%
| Taut-Line Hitch | Hitch | Adjustable tension line | 65-70%
| Sheet Bend | Bend | Join two different ropes | 55-65%
| Square Knot | Binding | Bind bandages/bundles | 45-55%
| Trucker’s Hitch | Compound | Mechanical advantage tightening | Varies by components
| Timber Hitch | Hitch | Drag logs, start lashings | 65-70%

### Knot Categories
*   **Loops:** Create a fixed circle; use for rescue harnesses, attaching rope to anchors, or creating attachment points.
*   **Hitches:** Attach rope to an object (pole, post, tree, ring); use for starting/finishing lashings.
*   **Bends:** Join two separate ropes; use for extending length or joining ropes of different diameters/materials.
*   **Binding Knots:** Wrap around a bundle to hold it tight; use for first aid bandages or securing packages.
*   **Compound Knots:** Create a pulley-like mechanical advantage (Trucker’s Hitch) for maximum tension.

### Common Failure Modes
*   **The Granny Knot:** Occurs when a square knot is tied with the same crossing direction twice (e.g., right-over-right).
*   **The Slip Bowline:** Occurs when the working end is passed through the initial loop in the wrong direction, resulting in a knot that tightens under load.
*   **Knots in Wet Rope:** Knots are harder to untie after wet-loading due to fiber swelling; use a slip version for quick release if untying wet rope is anticipated.
*   **Knots at the Wrong Place:** Every knot reduces rope strength by 20 to 50% when placed at a splice, abrasion point, or sharp bend.

## Notes
*   Strength Retention: Knots reduce rope strength by 20 to 50%.
*   Bowline Versatility: The bowline with a stopper knot is considered the single most versatile knot combination.
*   Square Knot Limitation: Never use the square knot to join two ropes under tension; the sheet bend should be used instead.
*   Bowline Looseness: The bowline can loosen when unloaded; it should be backed up with a stopper knot to prevent walking itself loose in situations where the rope goes slack and re-tightens.

## Knot Selection Quick Reference
| Need to… | Use this Knot | 
| :--- | :--- | 
| Make a loop that won’t tighten | Bowline | 
| Make a strong loop for heavy/critical load | Figure-8 loop | 
| Attach rope to a pole quickly | Clove hitch | 
| Make an adjustable-tension line | Taut-line hitch | 
| Join two ropes together | Sheet bend | 
| Tie off a bandage or bundle | Square knot | 
| Get maximum tightness on a line | Trucker’s hitch | 
| Drag or hoist a log | Timber hitch | 
| Stop rope from pulling through a hole | Figure-8 stopper | 
| Start or finish a lashing | Clove hitch |
