# Documentation

Human-readable documentation is organized first by language and then by reconstruction phase. Phases are approximate scenarios, not guaranteed predictions; categories and dependencies are independent from a document's location.

Each analyzed item must be stored as a single Markdown file in the relevant phase folder. The file name must match the specific item being analyzed, not a generic category name.

Example structure:

```text
docs/
├── it/
│   ├── 02-2-5-anni/
│   │   ├── carbonization.md
│   │   └── kiln-building.md
│   └── 03-5-15-anni/
│       └── iron-smelting.md
└── en/
    ├── 02-2-5-years/
    │   ├── carbonization.md
    │   └── kiln-building.md
    └── 03-5-15-years/
        └── iron-smelting.md
```

Each file must be divided into the sections: Material, System, Technology, Tools, Process, and an explicit statement of the objective to be achieved.
