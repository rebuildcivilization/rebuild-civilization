# 00 — Orientamento

Prima di costruire, valuta bisogni immediati, competenze disponibili, risorse locali, stagionalità e rischi.

## Checklist iniziale

- [ ] Salvaguardare acqua potabile, riparo, cibo e assistenza sanitaria.
- [ ] Mappare persone, strumenti, materiali e conoscenze presenti.
- [ ] Stabilire misure condivise e un registro delle osservazioni.
- [ ] Selezionare attività con il miglior rapporto beneficio/rischio.
- [ ] Conservare e duplicare informazioni essenziali.
