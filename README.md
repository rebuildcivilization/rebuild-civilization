# Rebuild Civilization

An open knowledge project for rebuilding technological civilization from zero.

## What is this?

Rebuild Civilization maps the technologies, knowledge, resources,
processes and dependencies required to progressively rebuild a technological
society.

## Reconstruction model

The project is organized into approximate reconstruction phases:

- 0 — Orientation
- 0–2 years — Survival and stabilization
- 2–5 years — Self-sufficiency and basic production
- 5–15 years — Initial industrialization
- 15–30 years — Advanced industrial infrastructure
- 30–50 years — Advanced technology
- 50+ years — Highly advanced technologies

## Repository

- `docs/` — human-readable documentation
- `knowledge/` — structured knowledge
- `sources/` — source catalog
- `templates/` — document templates
- `assets/` — visual resources
- `scripts/` — automation and validation
